# Bright Mind

A separate React + Vite competitive-exam practice platform. Study Material is intentionally excluded.

## Preview features
- Question bank with manual question creation and CSV import
- Exam creator: full mock, sectional, chapter-wise, PYQ and custom tests
- Student test runner with timer, question palette, answer saving and result summary
- Browser-local persistence for this preview build

## Run locally
`npm install` then `npm run dev`.

## Important
This preview stores data in the current browser using localStorage. It is functional for single-browser testing, not multi-user production. Shared database, secure admin/student authentication, and server-side PDF OCR are separate next-stage integrations.

Gyan Manch is a separate project and is not touched by this repository.
